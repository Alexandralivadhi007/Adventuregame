For our project we decided to make a text based adventure game, this game is
designed for everyone interested in decision making games and interactive storytelling.
The game will allow users to explore different scenarios, make different choices, and
experience different outcomes based on their decisions. We plan to implement features
like a, player health, an inventory system, and encounters with enemies or obstacles.
The player can win or lose depending on their decisions, and multiple endings will be
included. Input validation will ensure the user enters valid options, and clear instructions
will guide the user throughout the game. To build this we will use a couple different
concepts. Conditionals will be used to handle user decisions and determine outcomes.
Loops will allow the game to continue running until the player wins or loses. Arrays will
be used to store items such as the player’s inventory. Methods will organize the code
into reusable sections, such as displaying the menu, handling combat, or processing
choices. Classes will be used to represent key components like the player, enemies,
and items. Inheritance will be implemented by creating a base class; such as
“Character”, and extending it into subclasses like “Player” and “Enemy".
